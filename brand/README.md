# WordFlow brand kit

Open the guide with `npm run dev`, then go to http://localhost:1420/brand/. It covers the logo, color, type, motion, UI and voice.

| Folder | Contents |
| --- | --- |
| `logo/` | SVG: app icon, and the bare mark in lagoon blue, WordFlow blue, navy and white |
| `png/` | PNG: app icon at 1024, 512, 256 and 64 px; mark in four colors; lockup (icon + wordmark) in navy and white. All transparent. |

**Colors:** WordFlow Blue `#1F5FD6` · Deep Navy `#0B1A30` · Mist `#EEF3FA` · Foam `#FCFDFF` · Glow `#8FD0FF`. Brand gradient (icon) `#86E2D8 → #56B8DE → #3A7CBF`.

**Type:** Inter (SIL Open Font License). The name is always "WordFlow" with a capital F; the wordmark is Inter SemiBold with −4% tracking.

The app's tokens in `src/styles/globals.css` are the source of truth. If they change, update this kit.
